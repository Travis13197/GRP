# Supplementary figures (S1–S9)

All supplementary figures are regenerated by `figures/scripts/generate_final_supplementary.py` and verified by `figures/scripts/make_figures.py`.

| Figure | Title | One-line content |
|--------|-------|------------------|
| **S1** | Per-amino-acid intrinsic spectral-decay scaling | 20 panels; all 20 amino acids negative slope |
| **S2** | Per-protein C_geo–DMS scatter | 8 proteins, 84,361 mutations |
| **S3** | Amino-acid length-scaling fingerprint | heatmap, columns clustered, chemistry strip |
| **S4** | Hydrophobicity–charge conditional-response phase map | θ = 121°, CI 40°–154° |
| **S5** | Entropy state relation | observed-vs-predicted, standardized coefficients, residuals |
| **S6** | K-matrix transformation invariance + real-mutant low-stiffness directions | domain signal |
| **S7** | Folded-niche TSI, natural transition paths, direct NPZ transport | scope of the claim |
| **S8** | Five-level exclusion chain (V1–V5) | coupling irreducibility |
| **S9** | UMAP and t-SNE embeddings of the atlas and PolyG30 local chart | non-linear embeddings |

## Reproduction

```bash
python figures/scripts/make_figures.py supp
```

## Input data

The supplementary figures read the same committed `figures/data/` inputs as the main figures:

- `l2_intrinsic_geometry.csv` — the 1,373-system atlas (S1, S3, S9).
- `phase_l1_cgeo_kabsch_all_proteins.csv` — per-protein C_geo–DMS (S2).
- `systemwide_enhanced_geometry_v2.csv` — source-to-geometry phase map (S4, S5).
- `tables/phase_ensemble_b2_coupling_matrix_v2.csv`, `law2_validation_report.json` — coupling / irreducibility (S6, S8).
- `tables/phase6b_path_analysis_results.csv`, `results4_tau1_md.csv`, `results4_e50_theta_hq.json` — path and phase analyses (S4, S7).
- `ensembles/PolyX_PolyG_30/` — local chart (S9).

No external model downloads or GPU are required to regenerate S1–S9; all inputs are committed.

## Interpretation

Supplementary figures provide per-residue and per-protein detail, robustness checks, and the scope of the claims. They retain the same conservative, representation-dependent framing as the main figures: no physical force, energy, or universal law is claimed.
